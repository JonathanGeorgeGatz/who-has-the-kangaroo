# Who Has The Kangaroo? — free check-out / check-in system

Build It With AI · Episode 1. A QR-driven sign-out system for animals, tools, loaner laptops, camera gear, keys — anything your business signs out. Runs entirely inside one Google account (Google Sheets + Apps Script). No server, no subscription.

- **Setup guide:** open the GitHub Pages site for this repo
- **Download everything:** `who-has-the-kangaroo.zip`
- **The prompts, word for word:** `CLAUDE_PROMPT.txt`
- **The code:** `apps-script/`

Sample data only. Change `ORG_NAME`, the roster and `ADMIN_TOKEN` in `Code.gs` before you use it.
